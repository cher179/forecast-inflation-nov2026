# Будет ли годовая инфляция на 9 ноября 2026 года ниже 7,05%?

> **Мой прогноз: 45 %** · ИИ: 33 % · разрешится 11.11.2026 · автор ⟨твой ник⟩

## 1. Вопрос

| Поле | Значение |
|---|---|
| Событие | Годовая инфляция в РФ на 9 ноября 2026 года по расчёту Интерфакса (метод Минэкономразвития), опубликованная в материале о сводке Росстата от 11.11.2026 |
| Кто назначил дату | Росстат (еженедельная публикация по средам) |
| Исход «да» | Число годовой инфляции в материале Интерфакса ниже 7,05 % |
| Исход «нет» | 7,05 % и выше. Если сводку перенесли, но она вышла не позже 18.11.2026, считается она. Если не вышла до 18.11, вопрос аннулируется |
| Признак исхода | Число годовой инфляции «на 9 ноября» |
| Источник для проверки | ⟨ссылка на раздел «Экономика» на interfax.ru или на материал о сводке 11.11 после выхода⟩ |
| Дата разрешения | 11.11.2026 |
| Могу ли я повлиять на исход | Нет |

## 2. Прогноз

Вероятность исхода «да»: **45 %**.

## 3. Обоснование

1. Годовая инфляция на 26 октября составила 7,11 % после 7,15 % на 19 октября. Чтобы быть ниже 7,05 % к 9 ноября, нужно снижение ещё минимум на 0,07 п.п. за две сводки — [Интерфакс, 28.10.2026](https://www.interfax.ru/amp/1125579)
2. Недельная инфляция в октябре 2026: 0,11 % (6–12 окт), 0,05 % (13–19 окт), 0,08 % (20–26 окт). Среднее за последние две недели — около 0,065 % — [Интерфакс, 28.10.2026](https://www.interfax.ru/amp/1125579)
3. База прошлого года: за 28 октября – 5 ноября 2025 года цены выросли на 0,11 %, за 6–10 ноября — на 0,09 %, в сумме 0,20 % — [Интерфакс, 28 октября – 5 ноября 2025](https://www.interfax.ru/business/1056879), [Интерфакс, 6–10 ноября 2025](https://www.interfax.ru/business/1057642)
4. Расчёт автора: годовая инфляция снижается на разницу недельного роста этого и прошлого года. Для исхода «да» нужно, чтобы за две недели в 2026 году было не больше примерно 0,13 % (около 0,065 % в неделю). Это почти совпадает с последними двумя неделями (0,065 %), поэтому оцениваю исход как близкий к равновероятному, с небольшим перевесом в сторону «нет» из-за риска ускорения недельных цифр.
